# TrailSense UI Design System
Version: 1.0

---

## Design Philosophy

Build a modern, clean, premium web application inspired by:

- Linear.app
- Vercel Dashboard
- shadcn/ui
- Tailwind UI
- Notion
- Garmin Connect
- Strava
- Apple Human Interface

Prioritize readability, whitespace, rounded corners, subtle shadows, smooth animations, and accessibility.

Never create a cluttered interface.

Use a minimal SaaS dashboard aesthetic.
